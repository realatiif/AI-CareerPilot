# 🚀 AI-CareerPilot

AI-CareerPilot is an AI-powered career guidance system designed to help users analyze resumes, identify skill gaps, measure career readiness, and generate personalized career recommendations.

## ✨ Features

- Resume Analysis
- Skill Gap Detection
- Career Readiness Assessment
- Job Matching
- AI Career Recommendations
- Interactive Streamlit Dashboard

## 🛠️ Tech Stack

- Python
- Streamlit
- JSON
- NLP
- AI-Based Recommendation System

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/realatiif/AI-CareerPilot.git
```

Move into the project directory:

```bash
cd AI-CareerPilot
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
